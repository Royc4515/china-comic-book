## Changes made

Re-encoded from 320 kbps to 96 kbps MP3 (metadata/artwork stripped), with a 1.5 s fade-in and 3 s fade-out added so the tracks loop without a click. Playback level is set in `js/music.js` (`LEVEL`); both originals measure about -14.7 dB RMS.

## Which chapter plays what

Set per chapter in `js/data.js` (`music:`): calm chapters use "Asia"; the adventurous mountain, wall, and train chapters and the finale use "And The Sun Rises".

# "Roy in China" — Official Comic Book Production Bible & Prompt Guide

## 1. Project Specifications

* **Format**: Digital Graphic Novel / Web Comic Book
* **Page Aspect Ratio**: **2:3 (Vertical Portrait)** — Optimized for tablets, mobile web readers, and 2-page desktop flipbook readers.
* **Art Style**: Dynamic cel-shaded comic book / graphic novel avatar aesthetic with bold clean ink outlines, rich cinematic color palettes, expressive facial reactions, yellow narrative caption boxes, and integrated dynamic SFX (sound effects).
* **Narrative Arc**: Roy's real 14-day travel odyssey through Beijing, Xi'an, Zhangjiajie, and Shanghai with his companion team.

## 3. Dynamic Comic Page Grammar & Layout Rules

Unlike rigid grids, every page in this book follows cinematic pacing suited to the story beat:

1. **Wide Establishing Tier (Top)**: Sets scale, location, atmosphere, and historical context.
2. **Asymmetrical Focus Tiers (Middle)**: 2–3 character interaction panels, contrasting viewpoints (e.g. ancient vs. modern, reflection vs. humor).
3. **Kinetic Action / Climax Tier (Bottom)**: Diagonal panels, bleeding over gutters, incorporating bold hand-lettered SFX (`SKRRRR-ZZZT!`, `WHOOOOSH!`, `CLICK-WHIRR!`, `SIZZLE!`).
4. **Captions & Dialogue**:
   * *Yellow rectangular boxes*: Roy's reflective travel diary captions.
   * *Oval white speech balloons*: Natural, snappy character dialogue.
